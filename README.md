# Uthram Stores Website

A responsive multi-page website project for Uthram Stores, a neighbourhood convenience store at Meghamalhar Complex, Akkarapuram, Thrissur.

## Pages
- `index.html` — Home
- `products.html` — Product categories and JavaScript filtering
- `about.html` — Business overview
- `contact.html` — Contact details, WhatsApp and Google Maps link

## Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3 CDN
- Google Fonts

## Before publishing
1. Opening hours are set to Monday–Saturday, 9:00 AM–9:00 PM; confirm Sunday closure with the owner before final publication.
2. Confirm whether delivery is offered and the actual delivery radius.
3. Confirm any prices or availability labels that should be public.
4. Replace/add real store photos only after receiving permission.
5. Test all links on desktop and mobile.
